
# 🧮 Calculations Central

A fun, colorful, and responsive web application built with HTML, Tailwind CSS, and JavaScript to perform a variety of day-to-day calculations.

## 🚀 Features

- ✏️ **Standard Calculator** — Performs basic arithmetic operations.
- 🎂 **Age Calculator** — Calculates age based on date of birth and gives a fun message.
- 📈 **Compound Interest Calculator** — Calculates compound interest with inputs like rate, time, and frequency.
- 🏦 **Loan EMI Calculator** — Quickly calculate EMI based on loan amount, rate, and tenure.
- 💸 **Discount Calculator** — Two modes:
  - Calculate **discount %** from price difference.
  - Calculate **final price** from discount %.
- 🌡️ **Temperature Converter** — Convert between Celsius, Fahrenheit, and Kelvin.
- 📦 **Volume Calculator** — Calculate volume for cube, cuboid, and cylinder.

## 💡 How to Run Locally

1. **Clone this repo:**
   ```bash
   git clone https://github.com/your-username/calculations-central.git
   cd calculations-central
   ```

2. **Open the app:**
   - Double-click `index.html` OR
   - Use terminal:
     ```bash
     start index.html  # Windows
     open index.html   # Mac
     ```

3. **Optional: Use Live Server (VS Code)**
   - Install [Live Server Extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)
   - Right-click `index.html` > **Open with Live Server**
